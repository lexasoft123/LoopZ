LoopZ 0.2.0 — Windows preview

Route application audio into your own virtual LoopZ microphone with the native
Windows app. Save mixes and reopen them when you return to LoopZ.

This preview targets Windows 10 22H2 and Windows 11 on x64. The current package is a development workbench candidate, not a public
installer. Short stereo checks pass on the Windows 10 Dell and through an
existing microphone in the Windows 11 VM console; full installer acceptance
remains pending.

- Native Windows interface with the shared LoopZ design.
- A LoopZ virtual microphone driver and background device-management service.
- Saved routing with recovery across app restarts.
- Improved PCM16 sample conversion without changing the portable audio core.

On the Windows 11 VM, adding another microphone can temporarily change the
system’s automatic default microphone. The test restores the original default;
this behavior remains a known preview issue. Remote Desktop audio does not
validate local microphone access.

High-channel format switching remains under investigation. Driver upgrades can
require reselecting the LoopZ microphone in recording applications. Hardware and
third-party app compatibility is still being verified.

The workbench package requires the separately approved test-driver setup.
Production distribution requires application/installer signing and a
Microsoft-signed driver. No current-build end-to-end latency claim is included.
