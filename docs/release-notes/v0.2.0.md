LoopZ 0.2.0 — Native audio maintenance

Install, update and repair LoopZ’s audio components from Settings. The app uses
macOS authorization and a signed native helper; no developer scripts or separate
installer are needed.

- Journaled updates recover interrupted installations and roll back failures.
- Saved mixes reconnect after maintenance; system audio defaults stay unchanged.
- Updates reload only LoopZ’s verified isolated driver host. When macOS requires
  audio-service activation, the app explains the brief audio interruption and
  waits for an explicit Finish audio setup action.
- Apple Silicon and Intel app builds target macOS 14.2 or later.

Very small hardware buffers remain dependent on your audio hardware and load.
The hardware buffer target describes one buffer, not total end-to-end latency.
