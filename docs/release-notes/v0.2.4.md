LoopZ 0.2.4 — Safer audio buffers, quieter when hidden

Route apps, microphones and audio interfaces into a virtual microphone for Zoom,
recording or streaming. This macOS update refreshes LoopZ's audio core with
safer shared-buffer handling and a lighter resampler, and lets the window rest
when you are not looking at it.

- **Safer shared audio buffers.** When LoopZ changes an audio device's buffer size
  it now records the change, restores your original size when it no longer needs
  the smaller one, and keeps a recording alive if another app restores the buffer.
  LoopZ still only requests the buffer sizes it asked for before; nothing new is
  written to your devices.
- **Lighter resampling.** The audio core uses a precomputed filter table when it
  corrects for clock drift between devices. In zCore's own tests its output
  differs from the exact filter by at least 129 dB below the signal.
- **A resting window.** Meters and status polling pause while the LoopZ window is
  hidden or covered, and resume when it comes back.
- **Updated copy.** Interface text is refreshed in English, Russian and Simplified
  Chinese.

Install and repair audio components in LoopZ Settings. First-time driver
activation may ask you to choose **Finish audio setup**; sound briefly pauses
while macOS loads the driver. Ordinary updates keep the audio service running
and keep your saved mixes.

This release is for macOS 14.2 or later. Windows and Linux remain separate
experimental previews. One hardware buffer is not total end-to-end latency.
