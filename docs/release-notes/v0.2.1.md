LoopZ 0.2.1 — Experimental Windows preview

LoopZ is now available for Windows x64 with its native app, audio mixer and own
virtual microphone driver. Windows 10 22H2 and Windows 11 are the preview targets.

**This release uses a development-signed driver.** It requires administrator
setup, Windows Test Mode, a restart and usually disabling Secure Boot. Test Mode
changes driver trust for the whole PC. Read the included `WINDOWS-SETUP.md` before
installing; it also explains removal and restoring normal signing settings. This
is intended for test PCs, not ordinary production deployment.

- Mix application and hardware audio into LoopZ microphones for recording apps.
- Save routing and recover mixes after app restarts.
- Install, repair and remove microphones with the included native maintenance tool.
- The app/service carry their own Visual C++ runtime, fixing installation on a
  clean Windows system without a global developer runtime.

Known limits: creating another microphone can change Windows' automatic input
default, high-channel format switching is still under investigation, and hardware
and third-party app coverage is incomplete. Remote Desktop audio does not validate
local-device access. Driver upgrades can require reselecting microphones.

Short 48 kHz stereo checks pass on the Windows 10 Dell and through an existing
microphone in the Windows 11 VM console. These results do not establish every
format/client combination or an end-to-end latency guarantee. See `ACCEPTANCE.json`
for the exact tested source and binary provenance. No macOS installer is included
in this Windows preview release.
